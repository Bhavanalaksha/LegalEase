# Phase 8: Project Demonstration Phase
## Document: Google Drive & GitHub Submission Checklist

---

### 1. Mandatory SmartBridge Deliverables Checklist

#### Deliverable 1: Public GitHub Repository Link
- [ ] Create a new public repository on GitHub named `LegalEase` or `LegalEase-AI-Document-Generator`.
- [ ] Ensure all 8 phase directories and the complete codebase are committed.
- [ ] Verify that the repository visibility is set to **Public**.
- [ ] Verify that `.env` is included in `.gitignore` (do not commit your secret Gemini API key).

#### Deliverable 2: Public Google Drive Demo Video Link
- [ ] Record the demonstration video following `Demo_Video_Recording_Script.md`.
- [ ] Video format: MP4 (1080p recommended).
- [ ] Upload the video file to your Google Drive.
- [ ] **Crucial Step:** Right-click the uploaded file in Google Drive -> Click **Share** -> Change General Access to:
  > **"Anyone with the link" -> Role: "Viewer"**
- [ ] Test the link in an incognito browser window to guarantee it opens without requiring login!
