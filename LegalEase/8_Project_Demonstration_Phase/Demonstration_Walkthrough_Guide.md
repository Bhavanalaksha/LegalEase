# Phase 8: Project Demonstration Phase
## Document: Demonstration Walkthrough & Execution Guide

---

### Step-by-Step Recording Preparation Checklist

#### 1. Pre-Recording Setup
1. **Clean Screen & Browser:** Close unnecessary tabs. Open browser at `http://localhost:8501`.
2. **Audio Check:** Test microphone input levels; eliminate background noise.
3. **Start Services:** Run `run.bat` or launch the backend and frontend in separate terminals.
4. **Prepare Downloads Folder:** Clear previous test downloads so newly generated `.docx` and `.pdf` files appear at the top.

#### 2. Live Demo Flow (Follow Demo Script)
- [ ] **Step 1: Introduction (30s):** State Project Name, Team, and Problem Statement.
- [ ] **Step 2: Architecture (30s):** Mention FastAPI, Google Gemini 1.5 Pro, Streamlit, and Exporters.
- [ ] **Step 3: Scenario Input (45s):** Use the Quick Fill dropdown to select "Freelance Work Contract" (or type Jane Doe & TechNova Inc.).
- [ ] **Step 4: Generation (30s):** Click "Generate Document" and show the green success toast.
- [ ] **Step 5: Inspection (45s):** Scroll through the official preview card showing the formal legal structure.
- [ ] **Step 6: Edit Test (30s):** Click "Click to Edit Document", add a sample revision, and demonstrate responsiveness.
- [ ] **Step 7: Download Demonstration (60s):**
  - Download `.TXT`
  - Download `.DOCX` -> Open in Word / WordPad to show the logo and table.
  - Download `.PDF` -> Open in browser/Adobe to show the header emblem and footer.
- [ ] **Step 8: Conclusion (30s):** Show GitHub repository layout with 8 phases and deliver closing remarks.
